# The Neura1 film

`docs/demo/neura1-film-narrated.mp4` and `neura1-film-music.mp4` are rendered from `public/film.html`: every frame is a pure function of time, captured one
frame at a time at 60 fps, so motion is exact regardless of machine speed. The score is generated by `score.py` and
timed to the scenes. Everything here is free and open (Playwright, ffmpeg, numpy); nothing is sent anywhere.

```bash
# 1. With the app running and the demo reset, capture the screens and the impact data
python scripts/film/shots.py --base http://localhost:3000 --api http://127.0.0.1:8000
# 2. Serve the film page
python -m http.server 8765 --bind 127.0.0.1 -d scripts/film/public &
# 3. Check stills of every scene, then render the picture (about 8 minutes)
python scripts/film/stills.py
python scripts/film/render.py 60 film.mp4
# 4. Score it and put picture and sound together
python scripts/film/score.py film.mp4.json score.wav
ffmpeg -i film.mp4 -i score.wav -map 0:v -map 1:a -c:v copy -af "aecho=0.8:0.8:90|170:0.22|0.12,loudnorm=I=-16:TP=-1.5" \
       -c:a aac -b:a 256k -shortest -movflags +faststart neura1-film.mp4
```

Scenes, headlines and timings are in `public/film.html` (the `scene(...)` calls). Captured screens, the impact data and
renders are generated files and are not committed.
